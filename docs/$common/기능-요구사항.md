# 스트림

---

### 접근 방법

- 방 ID 입력 → URL 접속
- 공개 스트림 조회

### 인원 제한

- 1 : 1
- 1 : 5인?
- 1 : N

### 조회 권한

- 게스트 (아무나)
- 비밀번호 입력
- 개설자가 허용한 ID

## Host

- 이중 소리 방지

## Viewer

- 스트림 페이지에 들어왔지만, 송출 중이 아닐 경우 대기

> 방 X, 각 계정별 스트림 페이지가 있고, 송출이 시작되면 거기 뜨는 방식 (트위치 참고)
> 

### 사전점검 화면

- 레퍼런스 : 유튜브 스튜디오, 웹엑스 접속 전 점검 화면
- 마이크 권한
- 입력 레벨
- 서버 헬스 체크
    - 보이스팩 로딩 상태
    - GPU 서비스 모니터링
